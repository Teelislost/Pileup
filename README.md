# A Wizard's Secret Stash
A tool for artists, so that they can make mood boards and just keep all they're references in one place.

# Installing
Download the ZIP file, extract the folder, and open "A Wizard's Secret Stash" to open it up

# How to Use!
Click the blue rune to open a new board.

The "Add Reference" button let's you add photos to the screen. You can drag the reference around with the left mouse click. By holding down "Ctrl" and left mouse click, you can resize the image.

The "Add Textbox" button let's you add a textbox, if you want to leave notes.
